# trimm Mobile Monorepo

This repository contains the mobile clients for the trimm application.

- [Android Client (`android/`)](android/README.md) - The Android native client built with Kotlin and Jetpack Compose.
- [iOS Client (`ios/`)](ios/README.md) - The iOS native client built with Swift, SwiftUI, and SwiftData.

Both clients maintain exact feature parity and communicate with the `trimm-cloud` backend.
