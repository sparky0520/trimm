# iOS Client Implementation Guide

## Overview
This document outlines the architecture and implementation strategy for the native iOS Client (Swift, AVFoundation, CoreImage). The iOS app acts as a "Parser & Renderer" that takes the Universal Video JSON DSL generated by the AI and translates it into hardware-accelerated playback and export.

---

## 1. Architecture

The iOS client consists of three main layers:
1. **The Data Layer (Parser):** Swift `Codable` structs that strictly map to the JSON DSL schema.
2. **The Engine (AVFoundation Compiler):** A Swift class that takes the parsed structs and translates them into an `AVPlayerItem`.
3. **The UI (SwiftUI):** A declarative view that binds to the `AVPlayer` for previewing, alongside controls for exporting.

---

## 2. The Data Layer (Swift Structs)
You must define Swift structs that map perfectly to the JSON schema. Use Optionals (`?`) heavily to ensure the JSON decoder does not crash if the AI omits a non-essential key.

```swift
import Foundation

struct VideoDSL: Codable {
    let project: ProjectConfig
    let timeline: Timeline
}

struct ProjectConfig: Codable {
    let dimensions: Dimensions
    let fps: Int
    let durationMs: Int
}

struct Dimensions: Codable {
    let width: CGFloat
    let height: CGFloat
}

// ... define Timeline, Layer, Spatial, Compositing, and Effects matching the JSON schema
```

## 3. The Engine (AVFoundation Mapping)

This is the core translation layer. You will build a class (e.g., `AVCompositionBuilder`) that accepts a `VideoDSL` object and returns an `AVPlayerItem`.

### A. The Timeline (`AVMutableComposition`)
- Loop through `dsl.timeline.layers`.
- For each media layer, load the local `AVURLAsset`.
- Create a new `AVMutableCompositionTrack` of type `.video` for each layer.
- Use `insertTimeRange` to place the media onto the timeline at `startMs`. Time must be converted from milliseconds to `CMTime`.

```swift
// Helper for time conversion
func cmTime(from ms: Int) -> CMTime {
    return CMTime(value: CMTimeValue(ms), timescale: 1000)
}
```

### B. Transforms & Opacity (`AVMutableVideoCompositionLayerInstruction`)
For each track, create an instruction block.

- **Spatial Keyframes (Scale/Position/Rotation):** 
  Iterate over `layer.spatial.keyframes`. Use `layerInstruction.setTransformRamp(fromStartTransform:toEndTransform:timeRange:)`.
  *Note: AVFoundation handles transforms via `CGAffineTransform`. You must calculate the math to convert JSON x/y/scale into a transform matrix.*

- **Opacity Keyframes:** 
  Iterate over `layer.compositing.opacity.keyframes`. Use `layerInstruction.setOpacityRamp(fromStartOpacity:toEndOpacity:timeRange:)`.

### C. Audio Mixing (`AVMutableAudioMix`)
If a layer contains an `audio` block, you must construct an audio mix to control volume/fading.
- Ensure you added an `AVMutableCompositionTrack` of type `.audio` during the Timeline phase.
- Create an `AVMutableAudioMixInputParameters(track: audioTrack)`.
- Iterate over `layer.audio.volume.keyframes`. Use `setVolumeRamp(fromStartVolume:toEndVolume:timeRange:)`.
- Bundle all parameters into an `AVMutableAudioMix` and attach it to the `AVPlayerItem`.

### D. Effects & Color Grading (`CoreImage`)
To apply effects like `colorMatrix`, do NOT use the standard `AVMutableVideoCompositionInstruction`. Instead, use the specialized CoreImage handler:

```swift
let videoComposition = AVMutableVideoComposition(asset: composition, applyingCIFiltersWithHandler: { request in
    // 1. Get the current frame (source image)
    var outputImage = request.sourceImage
    let currentTimeMs = Int(request.compositionTime.seconds * 1000)
    
    // 2. Based on currentTimeMs, figure out which layer effects apply.
    // 3. Apply CIFilters (e.g., CIColorMatrix) to the outputImage.
    
    // Example: Applying a color matrix
    // let filter = CIFilter(name: "CIColorMatrix")
    // filter?.setValue(outputImage, forKey: kCIInputImageKey)
    // filter?.setValue(CIVector(...), forKey: "inputRVector")
    // outputImage = filter?.outputImage ?? outputImage
    
    // 4. Return the modified frame
    request.finish(with: outputImage, context: nil)
})
```
*Crucial Detail:* Because you evaluate effects frame-by-frame inside this handler, you can interpolate filter values based on the exact `currentTimeMs`.

## 4. The UI (SwiftUI)

The UI simply watches the Engine and plays the result.

```swift
import SwiftUI
import AVKit

struct VideoPlayerView: View {
    @State private var player: AVPlayer?
    let jsonDSL: String // Passed in from the AI Agent
    
    var body: some View {
        VStack {
            if let player = player {
                VideoPlayer(player: player)
                    .aspectRatio(9/16, contentMode: .fit)
            } else {
                ProgressView("Compiling Video...")
            }
        }
        .task {
            await compileVideo()
        }
    }
    
    func compileVideo() async {
        do {
            // 1. Decode JSON
            let data = jsonDSL.data(using: .utf8)!
            let dsl = try JSONDecoder().decode(VideoDSL.self, from: data)
            
            // 2. Build Engine
            let builder = AVCompositionBuilder()
            let playerItem = try await builder.build(from: dsl)
            
            // 3. Update Player
            self.player = AVPlayer(playerItem: playerItem)
            self.player?.play()
        } catch {
            print("Failed to compile DSL: \(error)")
        }
    }
}
```

## 5. Robustness & Fallbacks (CRITICAL)

The AI *will* occasionally hallucinate bad JSON. The iOS client must not crash.

1. **Unknown Effects:** In your `Decodable` structs or your switch statement for parsing `effect.type`, include a `default:` case. If an effect type is unknown (e.g., `"type": "lens_flare"`), print a debug log and simply skip applying it. Do not throw a fatal error.
2. **Missing Files:** If `source.url` points to a file that doesn't exist locally, catch the `AVAsset` loading error, skip that specific layer, and continue rendering the rest of the composition.
3. **Invalid Math:** Clamp values. If the AI provides an opacity keyframe of `-0.5`, clamp it to `0.0`. If it provides a scale of `0.0`, clamp it to `0.01` to prevent divide-by-zero matrix errors.
