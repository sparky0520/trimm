# Mobile roadmap

GitHub Issues in `sparky0520/ctrlb-mobile` are the canonical mobile ticket system.

Mobile owns:

- [Face, OCR, screen, and music perception](https://github.com/sparky0520/ctrlb-mobile/issues/1)
- [Video/proxy preparation and privacy controls](https://github.com/sparky0520/ctrlb-mobile/issues/2)
- [Media3 interactive preview/export parity](https://github.com/sparky0520/ctrlb-mobile/issues/3)
- [Detected orientation and quality ceilings](https://github.com/sparky0520/ctrlb-mobile/issues/4)
- [Chat/run activity UI](https://github.com/sparky0520/ctrlb-mobile/issues/5)
- [Google Play purchase, restore, and management UI](https://github.com/sparky0520/ctrlb-mobile/issues/6)
- [Physical-device verification](https://github.com/sparky0520/ctrlb-mobile/issues/7)
- [Reviewable fumble hints instead of threshold-only automatic cuts](https://github.com/sparky0520/ctrlb-mobile/issues/8)
