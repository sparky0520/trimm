# Documentation Maintenance

When making feature-level or structural code changes, you MUST always consider whether the project documentation needs to be updated.

- Documentation is centralized under the `docs/` folder in the repository root.
- Ensure any architectural or product-level changes (e.g. removing a feature like video uploads) are reflected across all relevant documentation files.
- If an API or major feature changes, actively check the docs using `grep_search` to find and update outdated information.
